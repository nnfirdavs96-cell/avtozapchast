Что выполняется на сервере и что доезжает до покупателя
Слева — наш файл. Справа — всё, что видит браузер, включая «посмотреть код страницы»
index.php — на сервере
$cenaPostavshika = 185;
$nacenka = 1.35;
$ostatok = 7;

// Считаем цену — покупатель этого не увидит
$cena = round($cenaPostavshika * $nacenka);

if ($ostatok > 5) {
    $status = 'В наличии';
} elseif ($ostatok > 0) {
    $status = 'Осталось мало';
} else {
    $status = 'Под заказ';
}
?>
<p>Цена: <strong><?= $cena ?></strong> сомони</p>
<p>Наличие: <?= $status ?> (<?= $ostatok ?> шт.)</p>
PHP
считает
то, что получил браузер
<p>Цена: <strong>250</strong> сомони</p>
<p>Наличие: В наличии (7 шт.)</p>
Ни 185, ни 1.35, ни слова «наценка» в браузер не попали. Уехал только результат — 250. Поэтому цены, скидки и права доступа считает сервер, а не JavaScript: до серверного кода покупатель не дотягивается в принципе.
