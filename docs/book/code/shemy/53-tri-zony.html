Три зоны git: где сейчас лежит ваш файл
Файл не «сохраняется в git» одним движением — он проходит две границы
Зона 1
Рабочая папка
Файлы, которые вы прямо сейчас видите в редакторе. Тут можно всё сломать — git это переживёт.
korzina.php — изменён
tovar.php — новый
git add
«вот эти файлы
пойдут в коммит»
Зона 2
Индекс
Черновик будущего коммита. Сюда кладут только то, что относится к одной задаче, — остальное ждёт.
korzina.php
git commit
«запиши в историю
под этим описанием»
Зона 3
История
Цепочка коммитов. Сюда уже не дотянуться случайно: любое состояние можно вернуть.
46f233c Заготовка корзины
4d4a492 Стили и каталог
Отсюда правило: git status отвечает на вопрос «что в какой зоне лежит». Пока не понимаете, что происходит, — набирайте git status.
