Так теряют деньги и нервы

  • «Сделаю за неделю» — не посмотрев объём
  • Работа без аванса, «рассчитаемся в конце»
  • Договорённости в голосовых сообщениях
  • «Мелкая доработка» без пересчёта сметы
  • Показ только в конце: «вот, готово»
  • Доступы к серверу и домену — не у заказчика

Так работают спокойно

  • Оценка по частям, с запасом в полтора раза
  • Аванс 30–50% до первой строки кода
  • Всё, о чём договорились, — письменно
  • Новая хотелка = новая строка сметы
  • Показ раз в неделю, хоть кусками
  • Домен и хостинг оформлены на заказчика
