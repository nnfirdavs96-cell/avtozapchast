# Глава 50. Чужой API: ключи, лимиты, ошибки

## 🎯 Зачем эта глава

Отправить запрос вы умеете. Но работа с чужим сервисом — это не про запросы.
Это про **чужие правила**, которые вы не контролируете.

Сервис может:

- потребовать ключ и следить, сколько вы просите;
- заблокировать вас за слишком частые обращения;
- изменить формат ответа без предупреждения;
- просто лечь на два часа;
- прислать данные, которые вы не ожидали.

В этой главе — как жить рядом с чужим сервисом и не сломаться. И главное —
**как не потерять доступ**, потому что для магазина, живущего на чужих ценах,
блокировка означает остановку работы.

## 📖 Ключи доступа

Почти любой серьёзный API требует ключ — чтобы знать, кто обращается,
и считать обращения.

```php
// Ключ передают по-разному, зависит от сервиса
http_json($url, ['zagolovki' => ['Authorization' => 'Bearer ' . API_KEY]]);
http_json($url, ['zagolovki' => ['X-API-Key' => API_KEY]]);
http_json($url . '?key=' . urlencode(API_KEY));
```

⚠️ **Ключ — это пароль.** Всё, что говорилось про пароль от базы в главе 32,
относится к нему полностью:

- **никогда в репозитории**;
- **никогда в JavaScript** — он виден покупателю;
- в git-ignored файле или в настройках сервера;
- меняется, если утёк.

### **Где хранить, чтобы менялось без программиста**

В нашем проекте применён приём, который стоит перенять: ключи хранятся
**в базе, в таблице настроек**, и редактируются через админку.

```sql
CREATE TABLE site_settings (
    kluch      VARCHAR(64) PRIMARY KEY,
    znachenie  TEXT NOT NULL,
    opisanie   VARCHAR(255) NOT NULL DEFAULT '',
    izmeneno   DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);
```

```php
function nastroyka(string $kluch, string $po_umolchaniyu = ''): string
{
    static $kesh = null;

    if ($kesh === null) {
        $stroki = zapros('SELECT kluch, znachenie FROM site_settings');
        $kesh = array_column($stroki, 'znachenie', 'kluch');
    }

    return $kesh[$kluch] ?? $po_umolchaniyu;
}
```

**Зачем так:** поставщик сменил ключ — владелец магазина заходит в админку
и вставляет новый. Без программиста, без доступа к серверу, без выкладки кода.

Для проекта, который передают заказчику, это принципиально.

## 📖 Лимиты: главная опасность

Каждый API ограничивает, сколько раз вы можете обратиться. Превысили —
получаете `429 Too Many Requests`, а при упорстве **блокировку аккаунта**.

⚠️ **Для магазина, живущего на чужих ценах, блокировка = остановка бизнеса.**
Это не преувеличение: без цен поставщика каталог показывать нечего.

### **Что запрещено делать**

В нашем проекте это записано отдельным правилом, и оно универсально:

> **Массовый перебор чужого API и парсинг сайтов поставщиков запрещены.**

Соблазн понятен: хочется скачать весь каталог поставщика, чтобы искать
у себя быстро. Но:

- это **тысячи запросов** за короткое время;
- сервис видит нагрузку и **банит аккаунт**;
- восстановить доступ бывает невозможно.

**Правильный путь: официальные выгрузки.** Почти любой поставщик даёт
прайс-лист файлом — раз в день, целиком, без нагрузки на API. Один файл
вместо десяти тысяч запросов.

API остаётся для того, для чего он нужен: **точечные запросы по одному
артикулу**, когда покупатель смотрит конкретный товар.

### **Ограничение частоты у себя**

Даже при аккуратном использовании стоит поставить собственный ограничитель:

```php
/**
 * Не чаще N обращений в минуту.
 * Считаем в файле — для одного сервера этого достаточно.
 */
function mozhno_zapros(string $servis, int $v_minutu = 60): bool
{
    $fail = __DIR__ . '/../storage/cache/limit_' . $servis . '.json';
    $sejchas = time();

    $zapisi = file_exists($fail)
        ? (json_decode((string) file_get_contents($fail), true) ?: [])
        : [];

    // Оставляем только последнюю минуту
    $zapisi = array_values(array_filter($zapisi, fn($t) => $sejchas - $t < 60));

    if (count($zapisi) >= $v_minutu) {
        return false;
    }

    $zapisi[] = $sejchas;
    file_put_contents($fail, json_encode($zapisi));

    return true;
}
```

```php
if (!mozhno_zapros('autoeuro', 60)) {
    // Не рвёмся в сервис, отдаём что есть
    return kesh_ceny($artikul) ?? [];
}
```

**Свой ограничитель дешевле блокировки.** Лучше показать покупателю кэш,
чем потерять доступ на неделю.

## 📖 Повторы при сбоях

Часть ошибок временные: сеть моргнула, сервис перезагружался. Такие запросы
имеет смысл повторить.

```php
/**
 * Запрос с повторами и растущей паузой.
 *
 * Повторяем только то, что имеет шанс сработать: сетевые сбои,
 * 429 и 5xx. Ошибки 4xx (кроме 429) повторять бессмысленно —
 * запрос неверный, и через секунду он останется неверным.
 */
function http_json_s_povtorami(string $url, array $nastroyki = [],
                               int $popytok = 3): array
{
    $posledniaya = null;

    for ($i = 1; $i <= $popytok; $i++) {
        try {
            $otvet = http_zapros($url, $nastroyki);
            $kod = $otvet['kod'];

            if ($kod >= 200 && $kod < 300) {
                return json_decode($otvet['telo'], true, 512, JSON_THROW_ON_ERROR);
            }

            // Не наша вина и есть шанс, что пройдёт позже
            if ($kod === 429 || $kod >= 500) {
                $posledniaya = new RuntimeException('Сервис ответил ' . $kod);
            } else {
                // 400, 401, 403, 404 — повторять незачем
                throw new RuntimeException('Сервис ответил ' . $kod . ': '
                    . mb_substr($otvet['telo'], 0, 200));
            }

        } catch (JsonException $e) {
            throw new RuntimeException('Ответ не JSON: ' . $e->getMessage());
        } catch (RuntimeException $e) {
            $posledniaya = $e;
        }

        if ($i < $popytok) {
            // Пауза растёт: 1, 2, 4 секунды
            sleep(2 ** ($i - 1));
        }
    }

    throw $posledniaya ?? new RuntimeException('Не удалось выполнить запрос');
}
```

⚠️ **Не повторяйте всё подряд.**

| Код | Повторять? | Почему |
|---|---|---|
| Сетевой сбой | **Да** | Могло моргнуть |
| `429` | **Да**, с паузой | Просто попросили подождать |
| `500`, `502`, `503` | **Да** | Проблема на их стороне |
| `400` | Нет | Запрос неверный |
| `401`, `403` | Нет | Ключ неверный или нет прав |
| `404` | Нет | Нет такого артикула |

Повторять `401` — значит долбить сервис неверным ключом. Это прямой путь
к блокировке.

**Растущая пауза** (1, 2, 4 секунды) — стандартный приём. Она даёт сервису
время прийти в себя и не создаёт лавины повторов.

## 📖 Предохранитель

Если сервис лежит десять минут, бессмысленно ходить к нему при каждом запросе
покупателя: каждый будет ждать таймаут в 10 секунд.

**Предохранитель** отключает обращения на время после серии неудач:

```php
/**
 * Предохранитель: после 5 неудач подряд отключаем сервис на 5 минут.
 * Так один упавший поставщик не тормозит весь сайт.
 */
function servis_dostupen(string $servis): bool
{
    $fail = __DIR__ . '/../storage/cache/predohranitel_' . $servis . '.json';

    if (!file_exists($fail)) return true;

    $s = json_decode((string) file_get_contents($fail), true) ?: [];

    if (($s['neudach'] ?? 0) < 5) return true;

    // Прошло ли время отключения
    if (time() - ($s['otklyuchen'] ?? 0) > 300) {
        @unlink($fail);   // пробуем снова
        return true;
    }

    return false;
}

function zapisat_rezultat(string $servis, bool $udachno): void
{
    $fail = __DIR__ . '/../storage/cache/predohranitel_' . $servis . '.json';

    if ($udachno) {
        @unlink($fail);
        return;
    }

    $s = file_exists($fail)
        ? (json_decode((string) file_get_contents($fail), true) ?: [])
        : ['neudach' => 0];

    $s['neudach'] = ($s['neudach'] ?? 0) + 1;
    if ($s['neudach'] >= 5) {
        $s['otklyuchen'] = time();
        error_log("Сервис $servis отключён на 5 минут после 5 неудач");
    }

    file_put_contents($fail, json_encode($s));
}
```

Применение:

```php
function cena_postavshika(string $artikul): ?array
{
    if (!servis_dostupen('autoeuro')) {
        return kesh_ceny($artikul);   // сервис отключён, отдаём что есть
    }

    try {
        $dannye = http_json_s_povtorami($url, $nastroyki);
        zapisat_rezultat('autoeuro', true);
        return $dannye;

    } catch (Throwable $e) {
        zapisat_rezultat('autoeuro', false);
        error_log('AutoEuro: ' . $e->getMessage());
        return kesh_ceny($artikul);
    }
}
```

**Смысл предохранителя: быстро отказать вместо долгого ожидания.** Покупатель
увидит страницу за полсекунды с последней известной ценой, а не будет ждать
десять секунд, чтобы получить ошибку.

## 📖 Не доверяйте формату ответа

Чужой сервис может изменить формат, прислать `null` там, где были данные,
или вернуть строку вместо числа.

```php
// ❌ Развалится на первом же неожиданном ответе
$cena = $otvet['data']['price']['value'];

// ✅ Аккуратно
$cena = $otvet['data']['price']['value'] ?? null;

if (!is_numeric($cena) || (float) $cena <= 0) {
    error_log('Странная цена от поставщика: ' . json_encode($otvet));
    return null;
}

$cena_diram = (int) round((float) $cena * 100);
```

**Правило: данные из чужого API — такие же внешние, как данные из формы.**
Проверяйте типы, диапазоны, обязательные поля.

### **Разбор ответа отдельной функцией**

```php
/**
 * Превращает ответ поставщика в наш формат.
 * Вся хрупкость собрана здесь: изменится их формат — правим одно место.
 */
function razobrat_otvet_postavshika(array $syroy): array
{
    $rezultat = [];

    foreach ($syroy['items'] ?? [] as $poz) {
        $artikul = trim((string) ($poz['code'] ?? ''));
        $cena    = $poz['price'] ?? null;
        $ostatok = $poz['stock'] ?? 0;

        // Позиция без артикула или цены нам бесполезна
        if ($artikul === '' || !is_numeric($cena) || (float) $cena <= 0) {
            continue;
        }

        $rezultat[] = [
            'artikul'   => mb_strtoupper($artikul),
            'nazvanie'  => trim((string) ($poz['name'] ?? '')),
            'cena_rub'  => (float) $cena,
            'ostatok'   => max(0, (int) $ostatok),
            'srok_dney' => max(0, (int) ($poz['delivery_days'] ?? 0)),
        ];
    }

    return $rezultat;
}
```

**Вся зависимость от чужого формата — в одной функции.** Поставщик переименовал
поле `price` в `cost` — правите одну строку, а не двадцать мест по проекту.

Этот приём называется **адаптер**, и он окупается при первом же изменении
на чужой стороне.

## 📖 Документируйте то, что узнали на практике

Чужие API редко документированы полностью. То, что вы выяснили опытом,
нужно записывать — иначе через полгода будете выяснять заново.

Из документации нашего проекта:

> ⚠️ **Тариф Parts-Catalogs: правила расхода НЕ ПОДТВЕРЖДЕНЫ.** Ранее считалось,
> что обход дерева и сбор схем тариф не тратят — письмо поставщика (999/1000)
> это опровергло. Пакетный сбор остановлен до ответа поставщика.

> **Токен комплектации протухает** — запросы начинают отвечать 404
> «Комплектация не найдена». Лечится только новым декодированием VIN
> (стоит запроса).

> **AutoEuro API ищет только по артикулу** и **не отдаёт фото**.

Три записи, каждая — результат потерянного времени. Записанные, они экономят
это время всем, кто придёт после.

**Заведите файл с наблюдениями по каждому внешнему сервису.** Что не работает,
что стоит денег, где подводные камни.

## 📖 Чек-лист работы с чужим API

Перед тем как подключать сервис:

- [ ] Прочитал документацию, особенно раздел про лимиты
- [ ] Знаю, что считается за обращение и сколько их можно
- [ ] Ключ хранится вне репозитория
- [ ] Есть таймаут на каждый запрос
- [ ] Есть кэш для того, что меняется редко
- [ ] Есть запасное поведение, если сервис недоступен
- [ ] Повторяю только временные ошибки
- [ ] Есть предохранитель на случай долгого сбоя
- [ ] Разбор ответа вынесен в отдельную функцию
- [ ] Проверяю типы и диапазоны в ответе
- [ ] Логирую ошибки с деталями
- [ ] Записал наблюдения в отдельный файл

## 🔤 Разбор по словам

| Запись | Что означает |
|---|---|
| **API-ключ** | Пароль к сервису. Хранить как пароль |
| `site_settings` | Ключи в базе, редактируются из админки |
| **Лимит** | Сколько обращений разрешено |
| `429 Too Many Requests` | «Слишком часто, подождите» |
| **Растущая пауза** | 1, 2, 4 секунды между повторами |
| **Предохранитель** | Отключить сервис после серии неудач |
| **Адаптер** | Функция разбора чужого формата в свой |
| Официальная выгрузка | Прайс файлом вместо тысяч запросов |

## ⚠️ Грабли

**Массовый перебор чужого API.** Прямой путь к блокировке аккаунта.

**Парсинг сайта поставщика.** То же самое, только ещё и незаконно
в большинстве случаев.

**Ключ в репозитории или в JavaScript.** Утечёт.

**Повторять ошибки 4xx.** Долбите сервис заведомо неверным запросом.

**Повторы без паузы.** Создаёте лавину при сбое.

**Нет предохранителя.** Упавший сервис тормозит весь сайт.

**Слепо доверять формату ответа.** Развалится при первом изменении.

**Разбор ответа размазан по коду.** Изменение формата — правка в двадцати
местах.

**Не записывать наблюдения.** Через полгода выясняете то же самое заново.

## 🔗 В бою

История проекта autodoc.tj — хорошая иллюстрация ко всей главе.

Магазин работает с двумя внешними сервисами: AutoEuro (цены) и Parts-Catalogs
через Tradesoft (каталоги по VIN). И оба преподнесли сюрпризы.

**AutoEuro** ищет только по артикулу и не отдаёт фотографии. Пришлось завести
свой словарь названий, чтобы работал поиск по словам, и подставлять свои фото
по совпадению артикула.

**Parts-Catalogs** оказался тарифицированным иначе, чем предполагалось.
Считалось, что обход дерева каталога не тратит квоту — оказалось, тратит.
Пакетный сбор данных пришлось остановить, а витрина теперь живёт
из накопленной библиотеки.

Отсюда и правило проекта: **всё, что уже получено от поставщика, сохраняется
у себя.** Повторный показ той же машины не стоит ни одного запроса.

**Общий вывод: чужой сервис — это риск, который нужно закладывать в архитектуру
с самого начала.** Не «а вдруг он изменится», а «он обязательно изменится,
что мы тогда будем делать».

## 📌 Итог

- Ключ API — **это пароль**. Вне репозитория, вне JavaScript.
- Ключи в таблице настроек редактируются **без программиста**.
- **Массовый перебор чужого API = блокировка.** Для магазина это остановка
  работы.
- Массовые данные берите из **официальных выгрузок**, API — для точечных
  запросов.
- Свой **ограничитель частоты** дешевле блокировки.
- Повторяйте только **сетевые сбои, 429 и 5xx**. С растущей паузой.
- **Предохранитель** отключает упавший сервис, чтобы не тормозить сайт.
- Данные из чужого API — **такие же внешние**, как из формы. Проверяйте.
- Разбор ответа — в **отдельной функции-адаптере**.
- **Записывайте наблюдения**: чужие API документированы неполно.
