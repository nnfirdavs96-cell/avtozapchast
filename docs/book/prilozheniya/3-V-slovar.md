# Приложение В. Словарь конструкций и терминов

> **Каждое слово и каждый знак** · Приложение В

Здесь собрано всё, что встречается в коде книги: не только слова, но и знаки
препинания. Потому что новичка чаще всего сбивает с толку именно `=>`, `::`
или `?:` — их нельзя набрать в поиске словами.

Разделы: знаки → HTML → CSS → JavaScript → PHP → SQL → общие термины.

---

## Знаки препинания в коде

| Знак | Название | Где | Что делает |
|---|---|---|---|
| `;` | точка с запятой | PHP, JS, SQL | **Конец команды.** Забыли — `syntax error` на следующей строке |
| `{ }` | фигурные скобки | везде | **Блок**: «всё, что внутри, — одно целое» |
| `( )` | круглые скобки | везде | Вызов функции, условие, группировка |
| `[ ]` | квадратные скобки | везде | Массив или обращение к элементу: `$a[0]` |
| `< >` | угловые скобки | HTML | Границы тега: `<div>` |
| `//` | двойной слэш | PHP, JS | Комментарий до конца строки |
| `/* */` | слэш-звёздочка | PHP, JS, CSS | Многострочный комментарий |
| `#` | решётка | PHP, CSS, SQL | Комментарий (PHP), `#id` (CSS), цвет `#B5411F` |
| `<!-- -->` | | HTML | Комментарий |
| `--` | два дефиса | SQL | Комментарий |
| `$` | доллар | PHP | **Начало имени переменной**: `$cena` |
| `.` | точка | PHP / JS / CSS | Склейка строк (PHP), доступ к свойству (JS), `.class` (CSS) |
| `->` | стрелка | PHP | Обращение к методу объекта: `$pdo->prepare()` |
| `=>` | толстая стрелка | PHP | Пара «ключ → значение»: `['id' => 1]` |
| `::` | двойное двоеточие | PHP | Обращение к статике: `PDO::ERRMODE_EXCEPTION` |
| `=` | равно | везде | **Присвоить**: положить значение в переменную |
| `==` | двойное равно | PHP, JS | Сравнить **со скидкой на тип**. Лучше не использовать |
| `===` | тройное равно | PHP, JS | Сравнить **значение и тип**. Используйте это |
| `!=` / `!==` | не равно | PHP, JS | Отрицание сравнения |
| `!` | восклицательный | PHP, JS | «НЕ»: `if (!$est)` — «если не есть» |
| `&&` | два амперсанда | PHP, JS | «И»: оба условия верны |
| `\|\|` | две палки | PHP, JS | «ИЛИ»: хотя бы одно верно |
| `??` | два вопроса | PHP, JS | «Или, если слева нет значения»: `$_GET['s'] ?? 1` |
| `?:` | вопрос-двоеточие | PHP, JS | Короткое условие: `$a > 0 ? 'да' : 'нет'` |
| `?->` | | PHP | Обратиться, только если объект не `null` |
| `+= -= *=` | | PHP, JS | `$s += 5` — то же, что `$s = $s + 5` |
| `++` / `--` | | PHP, JS | Увеличить/уменьшить на единицу |
| `%` | процент | PHP, JS | **Остаток от деления**: `7 % 2` = 1 |
| `...` | три точки | PHP, JS | «Разложить» массив в аргументы |
| `\|` | вертикальная черта | PHP | Объединение типов: `int\|null` |
| `&` | амперсанд | PHP | Передать по ссылке (используется редко) |
| `@` | собака | PHP | Заглушить ошибку. Только там, где это осознанно |
| `\` | обратный слэш | PHP | Разделитель пространств имён: `Magazin\Korzina` |
| `` ` `` | обратная кавычка | SQL | Имя столбца/таблицы, если совпало с ключевым словом |
| `%` | процент | SQL | «Любые символы» в `LIKE '%фильтр%'` |
| `*` | звёздочка | SQL | «Все столбцы»: `SELECT *` |
| `?` | вопрос | PHP+SQL | Место для значения в подготовленном запросе |

## HTML

| Слово | Что это | Простыми словами |
|---|---|---|
| **тег** | `<div>` … `</div>` | Команда разметки: «здесь начинается блок» |
| **элемент** | Тег + содержимое | Всё вместе: открывающий тег, текст, закрывающий |
| **атрибут** | `class="tovar"` | Свойство тега: имя и значение |
| **парный / одиночный** | `<p></p>` / `<img>` | Одни закрываются, другие нет |
| `<!DOCTYPE html>` | Объявление | «Это современный HTML» |
| `<html lang="ru">` | Корень документа | Язык страницы — для поиска и озвучки |
| `<head>` | Служебная часть | Не видна: кодировка, заголовок, стили |
| `<body>` | Тело | Всё, что видит человек |
| `<meta charset>` | Кодировка | Без неё — кракозябры |
| `<title>` | Заголовок вкладки | Он же в результатах поиска |
| `<div>` | **Блок без смысла** | Коробка. Занимает всю ширину, следующий — с новой строки |
| `<span>` | **Кусок строки без смысла** | Как маркер в тексте: выделить часть фразы |
| `<h1>`…`<h6>` | Заголовки | `<h1>` — главный, один на страницу |
| `<p>` | Абзац | Текст |
| `<a href>` | Ссылка | Переход. `href` — куда |
| `<img src alt>` | Картинка | `src` — файл, `alt` — текст, если не загрузилась |
| `<ul>`/`<ol>`/`<li>` | Списки | Маркированный / нумерованный / пункт |
| `<form action method>` | Форма | Куда и как отправлять данные |
| `<input>` | Поле ввода | Тип задаётся атрибутом `type` |
| `<label for>` | Подпись к полю | Клик по подписи ставит курсор в поле |
| `<select>`/`<option>` | Выпадающий список | Выбор одного из вариантов |
| `<textarea>` | Многострочное поле | Комментарий, описание |
| `<button>` | Кнопка | Внутри формы по умолчанию **отправляет** её |
| `<table>`/`<tr>`/`<td>` | Таблица / строка / ячейка | Только для табличных данных, не для вёрстки |
| `class` | Имя группы | Может повторяться. Основной способ вешать стили |
| `id` | Уникальное имя | **Одно на страницу.** Для якорей и JS |
| `name` | Имя поля формы | **Под этим именем значение придёт на сервер** |
| `value` | Значение поля | Что уже введено или выбрано |
| `required` | Обязательное | Браузер не даст отправить пустым |
| `placeholder` | Подсказка в поле | Исчезает при вводе. Не замена `label` |
| `data-*` | Свои данные | `data-id="42"` → в JS: `el.dataset.id` |
| **семантика** | Осмысленные теги | `<nav>` вместо `<div class="nav">` |

## CSS

| Слово | Что это | Простыми словами |
|---|---|---|
| **селектор** | `.tovar`, `#id`, `p` | Кого красим |
| **свойство** | `color`, `padding` | Что меняем |
| **значение** | `red`, `1rem` | На что меняем |
| **правило** | Селектор + `{ свойства }` | Одна запись целиком |
| **каскад** | Порядок применения | Кто победит при конфликте |
| **специфичность** | «Вес» селектора | `#id` сильнее `.class` сильнее тега |
| `!important` | Перебить всё | Крайняя мера — потом не отменить |
| **наследование** | Свойства переходят детям | Шрифт и цвет наследуются, отступы — нет |
| **блочная модель** | content → padding → border → margin | Из чего состоит размер элемента |
| `padding` | Отступ **внутри** рамки | Между рамкой и содержимым |
| `margin` | Отступ **снаружи** | Между этим элементом и соседями |
| `border` | Рамка | Толщина, тип, цвет |
| `box-sizing: border-box` | Считать padding в ширину | Ставится один раз на весь проект |
| `display: block` | Блочный | Вся ширина, с новой строки |
| `display: inline` | Строчный | По ширине содержимого, в строке |
| `display: flex` | Гибкая строка/колонка | Раскладка в одном направлении |
| `display: grid` | Сетка | Раскладка в двух направлениях |
| `display: none` | Скрыть | Элемент исчезает и не занимает места |
| `position: static` | Обычное | По умолчанию |
| `position: relative` | Сдвиг от своего места | И точка отсчёта для вложенных `absolute` |
| `position: absolute` | Свободное | Относительно ближайшего позиционированного родителя |
| `position: fixed` | Прибито к экрану | Не двигается при прокрутке |
| `position: sticky` | Липкое | Прилипает при прокрутке |
| `z-index` | Слой по глубине | Работает только с `position` не `static` |
| `flex: 1` | Занять свободное место | Растянуться |
| `gap` | Расстояние между элементами | Во flex и grid; отступы не схлопываются |
| `rem` | От шрифта страницы | Лучшая единица для отступов |
| `em` | От шрифта родителя | Осторожно: накапливается при вложении |
| `vh` / `vw` | Процент высоты/ширины экрана | Полноэкранные блоки |
| `@media` | Правило по условию | «Если экран шире 640px — вот так» |
| **mobile first** | Сначала для телефона | Потом расширяем через `min-width` |
| `:hover` | При наведении | На телефоне не работает — не прячьте туда важное |
| `:focus` | В фокусе | Обязательно оставлять видимым |
| `::before` / `::after` | Псевдоэлементы | Вставить оформление без лишних тегов |
| `var(--imya)` | Переменная | Цвета и размеры в одном месте |
| `transition` | Плавный переход | Между двумя состояниями |
| `overflow: hidden` | Обрезать лишнее | Всё, что не влезло, не видно |

## JavaScript

| Слово | Что это | Простыми словами |
|---|---|---|
| `const` | Постоянная | Имя нельзя переприсвоить. **По умолчанию берите её** |
| `let` | Переменная | Значение будет меняться |
| `var` | Старая переменная | Не используйте, живёт по другим правилам |
| **тип** | Вид значения | число, строка, логическое, массив, объект |
| `null` | «Пусто намеренно» | Значения нет, и это ожидаемо |
| `undefined` | «Не задано» | Переменная есть, значения не клали |
| `NaN` | «Не число» | Результат `'абв' * 2` |
| `true` / `false` | Логические значения | Да / нет |
| **объект** | `{ id: 1, cena: 250 }` | Набор пар «имя: значение» |
| **массив** | `[1, 2, 3]` | Список по порядку, счёт с нуля |
| **функция** | Кусок кода с именем | Вызывается, когда нужен |
| `function () {}` | Обычная функция | Классическая запись |
| `() => {}` | Стрелочная функция | Короче, и `this` из окружения |
| `return` | Вернуть результат | И выйти из функции |
| `if` / `else` | Если / иначе | Развилка |
| `for` / `while` | Циклы | Повторять |
| `for (const x of a)` | По значениям массива | Самый частый цикл |
| `break` / `continue` | Выйти / пропустить шаг | Управление циклом |
| `try` / `catch` | Попробовать / поймать | Обработка сбоя |
| `async` / `await` | Асинхронность | «Подожди ответа и иди дальше» |
| `document` | Вся страница | Точка входа к разметке |
| `querySelector` | Найти первый по селектору | `#id`, `.class` — как в CSS |
| `querySelectorAll` | Найти все | Возвращает список |
| `textContent` | Текст элемента | **Безопасно** для чужих данных |
| `innerHTML` | HTML внутри | **Опасно** с чужими данными — XSS |
| `classList` | Управление классами | `.add()`, `.remove()`, `.toggle()` |
| `addEventListener` | Подписаться на событие | «Когда кликнут — сделай это» |
| **событие** | click, submit, input | То, что произошло на странице |
| `e.preventDefault()` | Отменить обычное поведение | Форма не перезагрузит страницу |
| **делегирование** | Один обработчик на контейнер | Работает и для будущих элементов |
| `fetch` | Запрос к серверу | Загрузить данные без перезагрузки |
| `JSON.stringify` | Объект → строка | Чтобы отправить или сохранить |
| `JSON.parse` | Строка → объект | Обратно |
| `localStorage` | Хранилище в браузере | Переживает закрытие вкладки |
| `console.log` | Вывод в консоль | Главный инструмент отладки |
| **DOM** | Дерево элементов страницы | То, чем управляет JS |
| **debounce** | Отложить частые вызовы | Не дёргать сервер на каждый символ |

## PHP

| Слово | Что это | Простыми словами |
|---|---|---|
| `<?php` | Начало кода PHP | Всё после — выполняется на сервере |
| `declare(strict_types=1)` | Строгие типы | PHP не будет молча подгонять типы |
| `echo` | Напечатать | Вывести в страницу |
| `$peremennaya` | Переменная | Всегда начинается с `$` |
| `function` | Функция | Кусок кода с именем |
| `return` | Вернуть значение | И выйти |
| `array` / `[]` | Массив | Список или пары «ключ → значение» |
| `foreach` | Цикл по массиву | Самый частый |
| `if` / `elseif` / `else` | Развилка | Если — иначе если — иначе |
| `match` | Выбор из вариантов | Компактнее длинного `if` |
| `switch` | Старший брат `match` | Требует `break` |
| `isset()` | «Существует и не null» | Проверка перед использованием |
| `empty()` | «Пусто» | `0`, `''`, `[]`, `null` — всё пусто |
| `??` | Значение по умолчанию | `$_GET['s'] ?? 1` |
| `include` / `require` | Подключить файл | `require` падает, если файла нет |
| `class` | Класс | Чертёж объекта |
| `new` | Создать объект | По чертежу |
| `$this` | «Этот объект» | Внутри методов класса |
| `public` / `private` | Доступность | Снаружи видно / только внутри |
| `static` | Принадлежит классу | Не конкретному объекту |
| `namespace` | Пространство имён | «Фамилия» для класса |
| `use` | Импорт имени | Чтобы писать коротко |
| `try` / `catch` / `throw` | Исключения | Поймать сбой, а не упасть |
| `Throwable` | Любая ошибка | Ловит и `Exception`, и `Error` |
| `$_GET` | Данные из адреса | `?stranica=2` |
| `$_POST` | Данные из формы | При `method="post"` |
| `$_SESSION` | Данные сессии | Живут между страницами |
| `$_SERVER` | Данные о запросе | Адрес, метод, заголовки |
| `$_FILES` | Загруженные файлы | Фото товара |
| `session_start()` | Включить сессию | До любого вывода! |
| `header()` | Заголовок ответа | Редирект, тип содержимого |
| `htmlspecialchars()` | Обезвредить HTML | **Перед выводом любых чужих данных** |
| `password_hash()` | Хэш пароля | Пароли не хранят в открытом виде |
| `password_verify()` | Проверить пароль | Сравнить введённое с хэшем |
| **PDO** | Работа с базой | Единый способ для разных СУБД |
| `prepare()` / `execute()` | Подготовленный запрос | **Защита от SQL-инъекции** |
| `fetch()` / `fetchAll()` | Одна строка / все строки | Результат запроса |
| `lastInsertId()` | Id только что вставленной строки | Например, номер заказа |
| **транзакция** | «Всё или ничего» | `beginTransaction` → `commit` / `rollBack` |
| `var_dump()` | Показать значение и тип | Главный инструмент отладки |
| `json_encode` / `json_decode` | В JSON и обратно | Обмен с браузером и чужими API |
| **cURL** | Запрос к чужому серверу | PHP в роли браузера |

## SQL

| Слово | Что это | Простыми словами |
|---|---|---|
| **таблица** | Данные одного вида | Товары, заказы, покупатели |
| **строка / запись** | Один объект | Один товар |
| **столбец / поле** | Одно свойство | Цена, название |
| `PRIMARY KEY` | Первичный ключ | Уникальный номер строки |
| `AUTO_INCREMENT` | Автономер | База сама выдаёт следующий |
| `FOREIGN KEY` | Внешний ключ | Ссылка на строку в другой таблице |
| `NOT NULL` | Обязательное поле | Пустым быть не может |
| `DEFAULT` | Значение по умолчанию | Если не указали |
| `UNIQUE` | Не повторяется | Например, email |
| `INDEX` | Индекс | Оглавление: ускоряет поиск, замедляет запись |
| `SELECT` | Выбрать | Прочитать данные |
| `FROM` | Откуда | Из какой таблицы |
| `WHERE` | Условие отбора | Какие строки нужны |
| `ORDER BY` | Сортировка | `ASC` — по возрастанию, `DESC` — по убыванию |
| `LIMIT` / `OFFSET` | Сколько / с какой | Постраничный вывод |
| `LIKE` | Поиск по образцу | `'%фильтр%'` — вхождение |
| `IN` | Из списка значений | `WHERE id IN (1,2,3)` |
| `BETWEEN` | В диапазоне | `cena BETWEEN 100 AND 500` |
| `IS NULL` | Пусто | Сравнивать с `= NULL` нельзя |
| `INSERT` | Добавить строку | |
| `UPDATE` | Изменить | **Всегда с `WHERE`** |
| `DELETE` | Удалить | **Всегда с `WHERE`** |
| `JOIN` (`INNER`) | Соединить таблицы | Только совпавшие пары |
| `LEFT JOIN` | Соединить, сохранив левое | Даже если пары нет |
| `ON` | Условие соединения | По какому полю связаны |
| `GROUP BY` | Сгруппировать | «По брендам» |
| `HAVING` | Условие для групп | `WHERE` — для строк, `HAVING` — для групп |
| `COUNT` / `SUM` / `AVG` | Агрегаты | Сколько, сумма, среднее |
| `AS` | Псевдоним | Короткое имя столбца или таблицы |
| `EXPLAIN` | План запроса | Покажет, использован ли индекс |
| **транзакция** | Группа операций | Либо все, либо ни одной |
| `FOR UPDATE` | Заблокировать строки | Чтобы двое не купили последний товар |

## Общие термины

| **бэкенд** | То, что на сервере: PHP, база |

| **клиент / сервер** | Кто просит / кто отвечает |
| **запрос / ответ** | Основа всего веба |

| **GET / POST** | «Дай» / «На, обработай» |
| **API** | Способ программам говорить друг с другом |
| **JSON** | Формат обмена данными |
| **REST** | Соглашение о том, как строить API |
| **CRUD** | Создать, прочитать, изменить, удалить |
