# Сборка книги

Из `.md`-глав собирается один оформленный `kniga.html` и печатный `kniga.pdf`.

```bash
cd docs/book/tools && npm install    # один раз
cd .. && node tools/build.js         # HTML + PDF
node tools/build.js --html           # только HTML, быстро
```

Скриншоты для глав снимаются настоящим браузером:

```bash
node tools/snap.js <адрес|файл.html> img/имя.png [ширина] [высота] [css-селектор]
```

## Что где

| Файл | Зачем |
|---|---|
| `build.js` | Сборка: markdown → HTML → PDF. Шрифты вшиваются в файл, интернет при сборке не нужен |
| `style.css` | Всё оформление книги: типографика, врезки, печатная вёрстка |
| `snap.js` | Снимок экрана реальным браузером |

Врезки в главах делаются заголовком второго уровня с эмодзи:
`## 🎯 Зачем`, `## 📖 Разбираемся`, `## 🔤 Разбор по словам`, `## ⚠️ Грабли`,
`## 🏋️ Задачи`, `## 🔗 В бою`, `## 📌 Итог`. Сборщик сам превращает их в цветные блоки.
